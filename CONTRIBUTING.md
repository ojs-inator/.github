# Contributing to OJS-Inator

Repository-local `AGENTS.md`, contribution guides, templates, and test instructions override these organization defaults. Preserve any stronger repository-specific requirements.

- Keep changes small and in the repository that owns the behavior.
- Add focused regression tests for behavior changes and bug fixes.
- Do not overwrite unrelated contributor work.
- Never commit secrets, customer data, private infrastructure details, dumps, keys, or machine-specific configuration.
- For cross-repository or shared-contract changes, identify affected repositories, compatibility expectations, merge/release order, and validation evidence.

The canonical engineering and agent guidance lives in [`kmanweb-roadmap`](https://github.com/ojs-inator/kmanweb-roadmap): [agent handbook](https://github.com/ojs-inator/kmanweb-roadmap/blob/main/docs/agents/README.md), [shared contracts](https://github.com/ojs-inator/kmanweb-roadmap/blob/main/docs/agents/shared-contracts.md), [testing](https://github.com/ojs-inator/kmanweb-roadmap/blob/main/docs/agents/testing.md), [tooling](https://github.com/ojs-inator/kmanweb-roadmap/blob/main/docs/agents/tooling.md), and [ADRs](https://github.com/ojs-inator/kmanweb-roadmap/tree/main/adr).
