# OJS-Inator

OJS-Inator builds operational tooling for hosting, upgrading, migrating, and coordinating OJS/KMANWeb services.

Major repository groups include:

- operator orchestration and fleet tooling (`kmanweb-toolkit`, `kmanweb-fleet-ops`);
- service and lifecycle primitives (`ojs-toolkit`, `domain-toolkit`, mail tooling);
- node and bootstrap components (`kmanweb-node`, `kmanweb-server-bootstrap`);
- migration, backup, and supporting utilities;
- cross-repository architecture and coordination in [`kmanweb-roadmap`](https://github.com/ojs-inator/kmanweb-roadmap).

Start with the [shared agent handbook](https://github.com/ojs-inator/kmanweb-roadmap/blob/main/docs/agents/README.md), [contribution rules](https://github.com/ojs-inator/kmanweb-roadmap/blob/main/CONTRIBUTING.md), and [ADRs](https://github.com/ojs-inator/kmanweb-roadmap/tree/main/adr). Live coordination is tracked in the [OJS-Inator Engineering Project](https://github.com/orgs/ojs-inator/projects/1); issues, pull requests, and ADRs remain the source of truth.
